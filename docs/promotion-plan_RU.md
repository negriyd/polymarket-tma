# План первоначального продвижения

Как привлечь первых пользователей, пока реферальная программа ещё ничего не даёт. Главный риск сейчас — не то, что о боте не узнают, а то, что пришедшие не дойдут до первой ставки. Поэтому порядок такой: сначала путь до первой ставки, потом каналы привлечения, потом стимулы.

Статус на 2026-10-11. Обозначения: ✅ сделано · ⏳ сделано, ждёт проверки · ⬜ не сделано.

## 1. Путь до первой ставки

Сейчас от открытия бота до ставки 7 шагов: вход через Privy → «Подключить» торговлю Polymarket → «Активировать» торговый кошелёк → «Разрешить» → пополнение через мост (есть минимальная сумма) → минимум ордера в 5 акций (ограничение Polymarket) → подпись ордера. На каждом шаге часть людей уходит.

| Статус | Что | Где / как |
|---|---|---|
| ✅ | Подсказки «Первая ставка за 3 минуты»: 5 шагов, прогресс, кнопка следующего действия | Главная страница; скрывается, когда всё выполнено |
| ✅ | Просмотр подсказок для оператора: блок как у нового пользователя, на 0–4 выполненных шагах | «Статистика платформы» → «Просмотр подсказок»; только на этом устройстве |
| ✅ | Воронка: открыли → подключили кошелёк → пробовали поставить → поставили | «Статистика платформы» |
| ✅ | Понятные пояснения о минимуме ордера, шаге цены и состоянии рынка (дата окончания прошла / приостановлен / завершён с итогом) | Окно ставки и страница рынка |
| ⬜ | Закрытая бета на 20–50 знакомых и отдельный чат для отзывов | Ссылка `?startapp=sbeta`, смотреть, на каком шаге застревают |
| ⬜ | Исправить узкие места по итогам беты | По данным воронки и отзывам |
| ⬜ | Выяснить, действует ли минимум 5 акций для «рыночных» ордеров (исполняются сразу); если нет — режим «Купить по рынку от $1» | На polymarket.com рыночная покупка, похоже, возможна от $1 |

## 6. Ограничения

- Не направлять рекламу на страны, где Polymarket недоступен (в том числе США).
- Законы о рекламе ставок различаются по странам; в России такая реклама запрещена. Платную рекламу сначала согласовать с юристом.
- Правила площадок: Meta, TikTok и Google ограничивают рекламу ставок и крипто. Органический контент и Telegram проще платной рекламы.
- Не обещать заработок. Подавать как «узнай, что думает рынок» / «проверь свою интуицию», с пометкой о рисках и 18+.
- Не выдавать приложение за официальный продукт Polymarket: формулировка «клиент для Polymarket в Telegram».

## Ближайшие шаги

1. Проверочная ставка от $3 — убедиться, что Polymarket принимает ордера с кодом билдера.
2. Закрытая бета: 20–50 человек, ссылка `?startapp=sbeta`, чат для отзывов.
3. Создать канал «Рынок говорит» и подать заявки в каталоги мини-приложений.
4. Решить про 0% комиссии для ранних пользователей.
