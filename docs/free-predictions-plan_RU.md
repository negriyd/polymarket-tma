# «Прогноз без денег», счётчик точности и уведомления об итогах

План работ. Статус на 2026-10-11: этапы 1–5 реализованы и выкачены (образы `2026-10-11.20`); этап 6 — потом.

Обозначения: ⬜ не сделано · ⏳ в работе · ✅ сделано.

## Зачем

- **Снизить порог входа.** До первой реальной ставки 7 шагов, самый тяжёлый — пополнение деньгами. Прогноз без денег даёт попробовать продукт в первую минуту, без кошелька и подписей.
- **Научить механике:** цена как вероятность, акция, выплата после итога.
- **Дать повод вернуться:** итог рынка через дни или недели, уведомление в Telegram, счётчик точности.
- **Контент для продвижения:** «Прогнозист недели», «Спорим?», точность «7 из 9».

Прогнозы без денег — воронка к реальным ставкам, а не отдельный продукт. Каждый экран с результатом ведёт к реальной ставке.

## Что получает пользователь

1. **Прогноз в один тап.** На странице рынка рядом с «Купить» кнопки **«Прогноз: Да»** / **«Прогноз: Нет»**. Без кошелька, без подписи, без минимальной суммы.
2. **Метка с результатами** в профиле и на вкладке «Кошелёк»:
   - `Прогнозы: 7 ✓ · 2 ✗ · 78%`
   - `Ставки: 3 ✓ · 1 ✗` — отдельно, по реальным ставкам.
   Ожидающие итога в процент не входят.
3. **Сообщение от бота в Telegram** после итога рынка — и по прогнозам, и по реальным ставкам:
   - угадал: «✅ Ваш прогноз сбылся: «…» — Да. Точность: 8 из 10» + кнопка «Открыть рынок»;
   - реальная ставка выиграла: «🎉 Ставка выиграла: «…» — Да. К получению: $5.00» + кнопка **«Забрать выигрыш»** (вкладка «Кошелёк», Claim);
   - прогноз не сбылся — коротко: «❌ …» и кнопка к другим рынкам. О проигранных реальных ставках не пишем (решение 2).
4. **Переход к реальной ставке** после удачного прогноза: «Вы угадали. Реальная ставка $5 по цене прогноза принесла бы $8.40 → Сделать ставку».

## Ответ на вопрос «можно ли писать пользователю из приложения»

Да, но только тем, кто разрешил боту писать:
- Telegram передаёт флаг `allows_write_to_pm` в данных запуска мини-приложения. Наш бэкенд уже получает его, но пока не сохраняет.
- Если разрешения нет, мини-приложение может попросить его штатным диалогом Telegram `WebApp.requestWriteAccess()`. Это одна кнопка «Разрешить», без перехода в чат с ботом.
- Лучший момент для такой просьбы — сразу после первого прогноза или ставки: «Сообщить вам итог?».
- Если пользователь заблокировал бота, Telegram вернёт ошибку 403. Тогда снимаем флаг и больше не пишем.

## Работы

### 1. Данные (бэкенд, миграция V7)

| Статус | Что |
|---|---|
| ✅ | `app_user.allows_messages` (boolean) — сохранять `allows_write_to_pm` при каждом входе; снимать при ответе 403 от Telegram |
| ✅ | Таблица `prediction`: `user_id`, `condition_id`, `market_id`, `outcome_index`, `outcome_label`, `price_at_prediction`, `created_at`, `resolved_at`, `correct` (null — ждёт итога). Один активный прогноз на рынок; повторный нажим меняет выбор, пока рынок открыт |
| ✅ | Таблица `result_notification`: `user_id`, `condition_id`, `kind` (`PREDICTION` / `BET`), `sent_at`, `status` — защита от повторных сообщений |
| ✅ | Для реальных ставок: исполненные сделки брать из Polymarket data API (`/trades?user=<торговый кошелёк>`), а не из `order_audit`. Ордер в стакане мог не исполниться или быть отменён |

### 2. API

| Статус | Метод | Что делает |
|---|---|---|
| ✅ | `POST /api/predictions` `{marketKey, side}` | Создать или изменить прогноз (только открытые рынки, `acceptingOrders`) |
| ✅ | `GET /api/predictions?status=open\|resolved` | Мои прогнозы |
| ✅ | `GET /api/me/track-record` | Метка: прогнозы ✓/✗/ожидают, ставки ✓/✗/ожидают, точность |
| ✅ | `POST /api/me/notifications` `{enabled}` | Включить/выключить сообщения об итогах (после `requestWriteAccess`) |

### 3. Фоновая задача «итоги рынков»

Аналог существующей `MarketResolutionJob` (сейчас — для внутренних ставок), раз в 10 минут:

| Статус | Шаг |
|---|---|
| ✅ | Собрать рынки, по которым есть неразрешённые прогнозы или реальные позиции пользователей |
| ✅ | Пакетно запросить их в Gamma (`/markets?condition_ids=…&closed=true`, как уже делает `findByConditionId`) |
| ✅ | Для закрытых с итогом (цена исхода 1/0): отметить прогнозы `correct = true/false`; для реальных ставок посчитать выигрыш по исполненным сделкам |
| ✅ | Отправить сообщения через `TelegramBotClient.sendMessage` (метод добавить): язык пользователя (`language_code`), кнопка `t.me/<бот>?startapp=m_<id>` или на «Кошелёк» для Claim |
| ✅ | Ограничить скорость отправки (Telegram: ~30 сообщений в секунду на бота) и записывать каждую отправку в `result_notification` |
| ✅ | Рынок «закрыт, ждёт итога» — не трогать, проверить в следующий раз |

## Принятые решения (2026-10-11)

1. **«Рынок мнений» не показываем** — ни прогнозы друзей, ни долю пользователей приложения за «Да».
2. **Сообщения:** об итогах прогнозов (сбылся и не сбылся) и только о **выигранных** реальных ставках. О проигранных ставках не пишем.
3. **Не больше 3 сообщений в сутки** одному пользователю; если итогов больше — последние идут одной сводкой.
4. **Рейтинг «Прогнозист недели» — публичный**, с именами из Telegram.
