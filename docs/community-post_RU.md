# Пост для сообществ

Пост в форме личного отзыва: от первого лица, о том, как приложением пользуются, а не рекламный список. Автор — разработчик, это сказано в тексте: выдавать пост за отзыв постороннего пользователя нельзя, это обман аудитории и нарушение правил большинства сообществ.

Ссылка с меткой `scommunity` — переходы видны в «Статистике платформы» → «Каналы». Для каждого сообщества можно ставить свою метку (`s<метка>`). Картинку к посту можно взять на любом рынке: «Картинка для постов».

Перед публикацией:
- не направлять пост на страны, где Polymarket ограничен (Россия, Украина, Бразилия, Аргентина, США, Великобритания и др. — см. [partner-candidates_RU.md](partner-candidates_RU.md));
- приложить свою реферальную ссылку вместо общей, если публикуете от своего аккаунта;
- подставить свой реальный счёт точности вместо `[N из M]` (вкладка «Кошелёк» → «Мои результаты») и не приписывать себе того, чего не было: выдуманные цифры в «отзыве» — тоже обман.
